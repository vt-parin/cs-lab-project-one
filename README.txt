StockSmart - how to build and run

Put all .java files in ONE folder (the code uses the default package):
  GroceryList, ListItem                 (Parin)
  GroceryStore, Main, IntegrationTest   (team)
  Item, Inventory                       (Ian)
  User, Customer, Worker                (Isaac)

Compile:   javac *.java
Run app:   java Main
Run tests: java GroceryListTest
           java IntegrationTest
